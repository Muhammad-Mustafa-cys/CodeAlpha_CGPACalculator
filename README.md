# CodeAlpha CGPA Calculator

A C++ based CGPA Calculator developed as part of the **CodeAlpha C++ Programming Internship**.

## Task Description

This program calculates a student's GPA/CGPA using the grades and credit hours of their courses.

## Features

- Takes the number of courses as input
- Takes the grade and credit hours for each course
- Calculates total credit hours
- Calculates total grade points
- Calculates the GPA/CGPA
- Displays the individual course information and final result

## Technologies Used

- C++
- Standard C++ libraries

## How to Run

1. Open the C++ source file in a C++ compiler or IDE.
2. Compile the program.
3. Run the program.
4. Enter the required course, grade, and credit-hour information.
5. The program calculates and displays the result.
